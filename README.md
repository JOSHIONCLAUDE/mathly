# Mathly
A calculator that solves almost any school maths problem, with steps: scientific calculator, equations (linear, quadratic, cubic, systems, inequalities, trig/log), algebra (simplify, expand, factor, partial fractions), calculus (derivatives, integrals, limits, series), graphing with zeros and intersections, matrices, statistics and probability, number theory, fractions, percent, units, geometry and money tools. Works offline. No ads, no tracking.

Open / install: https://joshionclaude.github.io/mathly/ · Downloads: https://joshionclaude.github.io/mathly/download.html

Built with [math.js](https://mathjs.org) and [Nerdamer](https://nerdamer.com) (both open source).
